اتصال به گیت‌هاب

برای ذخیرهٔ تغییرات، پنل باید مستقیماً به ریپوی گیت‌هاب سایت وصل شود.

یک توکن دسترسی بسازید: در گیت‌هاب به Settings → Developer settings → Fine-grained tokens بروید، Repository access را روی همین ریپو محدود کنید و در Permissions بخش «Contents» را روی Read and write بگذارید. توکن را همین‌جا وارد کنید — فقط در همین مرورگر ذخیره می‌شود و به‌جای دیگری فرستاده نمی‌شود.
