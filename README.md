# منوی مش کافی

سایت منوی آنلاین مش کافی، به همراه پنل مدیریت برای ویرایش خودکار منو، عکس‌ها، رنگ‌ها و اطلاعات کافه — بدون نیاز به دانش برنامه‌نویسی.

## لینک‌ها

- **منوی عمومی (برای مشتری‌ها):** `https://armanstudy.github.io/mash-coffee/`
- **پنل مدیریت:** `https://armanstudy.github.io/mash-coffee/admin/`
- **صفحهٔ QR کد (برای چاپ روی میز):** `https://armanstudy.github.io/mash-coffee/qr.html`

> این لینک‌ها بعد از فعال‌سازی GitHub Pages کار می‌کنند (مرحلهٔ زیر).

## راه‌اندازی اولیه (فقط یک‌بار)

### ۱. فعال‌سازی GitHub Pages
1. وارد ریپوی `armanstudy/mash-coffee` در گیت‌هاب شوید.
2. به **Settings → Pages** بروید.
3. زیر «Build and deployment» گزینهٔ Source را روی **Deploy from a branch** بگذارید، شاخه (Branch) را **main** و پوشه را **/ (root)** انتخاب کنید و Save بزنید.
4. بعد از چند دقیقه، سایت روی آدرس بالا در دسترس است.

### ۲. ساخت توکن دسترسی برای پنل مدیریت
پنل مدیریت برای ذخیرهٔ تغییرات (متن، عکس، رنگ و...) مستقیماً به گیت‌هاب وصل می‌شود و نیاز به یک «توکن دسترسی» دارد:

1. در گیت‌هاب به آدرس زیر بروید:
   `Settings (تنظیمات حساب) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token`
2. یک نام دلخواه بدهید (مثلاً «پنل مش کافی»).
3. **Repository access** را روی «Only select repositories» بگذارید و ریپوی `mash-coffee` را انتخاب کنید.
4. در بخش **Permissions → Repository permissions**، مقابل **Contents** گزینهٔ **Read and write** را انتخاب کنید (فقط همین یکی لازم است).
5. تاریخ انقضا (Expiration) را متناسب با نیازتان تنظیم کنید (مثلاً ۱ سال، یا No expiration).
6. Generate token را بزنید و توکن ساخته‌شده را کپی کنید (فقط یک‌بار نمایش داده می‌شود).

### ۳. اتصال پنل مدیریت
1. به آدرس پنل مدیریت بروید و با رمزی که برایتان تنظیم شده وارد شوید.
2. نام کاربری گیت‌هاب (`armanstudy`)، نام ریپو (`mash-coffee`) و توکنی که ساختید را وارد کنید.
3. توکن فقط در همان مرورگر (localStorage) ذخیره می‌شود و به هیچ سروری جز گیت‌هاب فرستاده نمی‌شود.

## کار روزمره با پنل مدیریت

- **تنظیمات و ظاهر:** نام کافه، شعار، آدرس/تلفن/اینستاگرام، ساعت کاری، رنگ‌های حالت روشن و تاریک، فونت‌ها، آیکن سربرگ، و روشن/خاموش کردن کل منو.
- **دسته‌ها و آیتم‌ها:** افزودن/حذف/جابه‌جایی دسته و آیتم، ویرایش نام/قیمت/توضیح/برچسب، آپلود عکس هر آیتم، و فعال/غیرفعال کردن هر دسته یا آیتم به‌صورت جداگانه (مثلاً غیرفعال کردن موقت «صبحانه»).
- تمام تغییرات فوراً در «پیش‌نمایش زنده» سمت پنل دیده می‌شوند.
- با زدن دکمهٔ **«ذخیره و انتشار»**، تغییرات مستقیماً روی گیت‌هاب کامیت می‌شوند و طی چند ثانیه تا چند دقیقه در سایت اصلی ظاهر می‌شوند.
- دکمهٔ **«بازخوانی از گیت‌هاب»** آخرین نسخهٔ ذخیره‌شده را دوباره می‌خواند (برای وقتی چند نفر ممکن است هم‌زمان ویرایش کنند).

## نکتهٔ امنیتی

رمز ورود به پنل فقط یک قفل سادهٔ ورودی است. امنیت واقعی از طریق توکن گیت‌هابی تأمین می‌شود که فقط شما آن را دارید و فقط در مرورگر خودتان ذخیره شده. توصیه می‌شود:
- لینک پنل مدیریت را در جای عمومی (مثل خود منو یا اینستاگرام) منتشر نکنید.
- اگر گوشی/لپ‌تاپتان گم شد، توکن را از گیت‌هاب (همان صفحهٔ Fine-grained tokens) باطل (Revoke) و یک توکن جدید بسازید.

## ساختار فایل‌ها

```
index.html          صفحهٔ عمومی منو
menu-data.json       تمام محتوای منو، رنگ‌ها و تنظیمات (توسط پنل مدیریت نوشته می‌شود)
qr.html              صفحهٔ QR کد قابل چاپ
images/              عکس‌های آیتم‌های منو (توسط پنل مدیریت آپلود می‌شود)
assets/              فایل‌های مشترک ظاهر و رندر منو
admin/               پنل مدیریت
```
